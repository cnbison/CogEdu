## 4. 教师复核清单（P0-1b 人工评估的输入）

**总体**：三份题库按"教研组审卷"标准通审——重点核对题干表述是否符合本地教材版本用语、难度梯度是否匹配目标学生、rubric 四档描述是否与本校评分惯例一致。

**起草方自报的把握不足项**（按风险排序）：

- 化学 Q13（缓慢氧化）：「氧化」术语正式出现在第二单元，本单元以前移生活常识方式切入，**有超纲风险**——建议教师裁定保留前移或换题
- 化学 Q18（呼出气体探究实验设计）：CREATE 层级的评分锚（等量/对照/现象结论分离）是否贴合真实课堂标准需教研确认
- 化学 Q20（1）：生成物写"不溶于水的白色沉淀"未点破碳酸钙名称（贴合第一单元不学化学式）——教师可决定是否明确化
- 化学 Q08 D 选项（"火焰里的还是蜡烛"）措辞偏口语，可打磨
- 数学 Q13（含绝对值方程）：七上课标外拓展题，用于 L3/L4 区分度，教师裁定去留
- 物理 Q12（量筒俯仰视）：偏差方向类题目最依赖配图/演示，文字逻辑已复核但建议配套示意图
- 物理 Q13（误差分析）：数值链自洽（52+1.6=53.6），但显式给出沾水质量削弱了推理成分——教师可决定改为纯定性分析
- 物理 Q16/Q20（"铁比棉花重"辨析 / 体积密度评价）：开放题 judge 判分依赖采分点（"相同体积"前提 / 控制变量 / 反例），LLM judge 的宽容度需在 P0-1b 实测验证
- 物理 Q20 反例中木头密度"约 0.6 g/cm³"：不同木种 0.4-0.9 不等，教师可按教辅口径微调
- 物理 Q10（m-V 图像文字化）：无图可读的设计规避了配图依赖，教师可决定是否补图
- 全部 MIRT 参数（difficulty/discrimination/guessing）为 AI 按难度梯度与题型惯例的估值，**未经真实作答数据校准**——P0-1b 实测后应以实际答对率回标
